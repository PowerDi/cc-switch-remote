# 1.2 インストールガイド

## 公式チャネルとシステム要件

CC Switch Remote は **[GitHub Releases](https://github.com/PowerDi/cc-switch-remote/releases)** またはプロジェクトのソースリポジトリからのみ入手してください。支払い、チャージ、ログイン情報の入力を求める「CC Switch Remote」サイトやクライアントは公式ではありません。

| システム | 最低バージョン | アーキテクチャ |
|------|----------------|----------------|
| Windows | Windows 10 以上 | x64 / ARM64 |
| macOS | macOS 12 (Monterey) 以上 | Intel (x64) / Apple Silicon (arm64) |
| Linux | glibc 2.35+ と WebKitGTK 4.1（下記の [Linux](#linux) セクションを参照） | x64 / ARM64 |

インストールパッケージは [GitHub Releases](https://github.com/PowerDi/cc-switch-remote/releases) から入手できます。

## 任意：管理するツールのインストール

CC Switch Remote 自体には Node.js などのランタイムは不要です。CC Switch Remote が管理するのは、すでにインストール済みの Claude Code や Codex などのツールです。まだインストールしていないツールは、先に CC Switch Remote をインストールしてから、次のいずれかの方法でインストールできます。

### 方法 1：CC Switch Remote からワンクリックでインストール（推奨）

サイドバー下部の「アプリ」をクリックすると、リストに各ツールの現在のバージョンと最新バージョンが表示されます。未インストールのツールにはインストールボタンがあり、インストール済みのツールは個別に更新できます。ここでサイドバーに表示するアプリを選ぶこともできます。対応ツールは Claude Code、Codex、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes、Pi、MiniMax Code です。Claude Desktop はデスクトップアプリのため、ここではインストールできません。詳細は [1.3 インターフェース概要](./1.3-interface.md#アプリ管理ページ) を参照してください。

### 方法 2：各ツールの公式手順でインストール

| ツール | インストールコマンド（macOS / Linux） |
|------|---------------------------|
| Claude Code | `curl -fsSL https://claude.ai/install.sh \| bash` または `npm i -g @anthropic-ai/claude-code` |
| Codex | `npm i -g @openai/codex` または `brew install --cask codex` |
| Gemini CLI | `npm i -g @google/gemini-cli` |
| Grok Build | `curl -fsSL https://x.ai/cli/install.sh \| bash` または `npm i -g @xai-official/grok` |
| OpenCode | `curl -fsSL https://opencode.ai/install \| bash` または `npm i -g opencode-ai` |
| OpenClaw | `npm i -g openclaw` |
| Hermes | `curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh \| bash` |
| Pi | `npm i -g @earendil-works/pi-coding-agent` |

Claude Desktop、MiniMax Code（方法 1 でインストール可能）、および Windows でのインストール方法は、各ツールの公式ドキュメントを参照してください。

npm でインストールするには、先に Node.js が必要です。必要なバージョンはツールによって異なります（例：Claude Code は 22 以上、OpenClaw は 24.16 以上の 24.x または 26.1 以上）。現行の LTS 版をインストールすることをおすすめします。バージョンが足りない場合は npm が知らせてくれます。

> 💡 **ヒント**：中国国内で npm のダウンロードが遅い場合は、コマンドの末尾に `--registry=https://registry.npmmirror.com` を付けるか、ミラーをグローバルに設定してください：
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```
> ミラーの同期が遅れることがあります。公式より古いバージョンがインストールされた場合は、一時的に公式レジストリ `https://registry.npmjs.org` に戻してください。

## Windows

### インストーラー方式

1. [Releases ページ](https://github.com/PowerDi/cc-switch-remote/releases) から `CC-Switch-Remote-v{バージョン}-Windows.msi` をダウンロード（ARM 版 Windows では `CC-Switch-Remote-v{バージョン}-Windows-arm64.msi`）
2. インストーラーをダブルクリックして実行
3. 指示に従ってインストール

インストール先の選択画面には **Create a desktop shortcut**（デスクトップショートカットを作成）オプションがあります。チェックを外すとデスクトップショートカットの作成をスキップでき、インストール後はスタートメニューから起動できます。新規インストールでは既定で選択されます。アップグレード時はショートカットの有無を引き継ぎ、削除済みのショートカットは自動で再作成されません。アップグレード時にチェックを外すと、既存のデスクトップショートカットも削除されます。デスクトップショートカットを作成できない場合（デスクトップが読み取り専用、セキュリティソフトによるブロックなど）は、そのショートカットを省略してインストールを続行し、中断やロールバックは行いません。

サイレントインストールでは、`CREATEDESKTOPSHORTCUT=0` を指定するとデスクトップショートカットの作成をスキップできます。

```powershell
msiexec /i "CC-Switch-Remote-v{バージョン}-Windows.msi" /qn CREATEDESKTOPSHORTCUT=0
```

注意：インストーラーを実行しても何も起こらない場合は、ファイルを右クリックしてメニューから `プロパティ` を開き、`全般` タブの `セキュリティ` で `許可する` にチェックを入れてください

### ポータブル版（インストール不要）

1. `CC-Switch-Remote-v{バージョン}-Windows-Portable.zip` をダウンロード（ARM 版は `CC-Switch-Remote-v{バージョン}-Windows-arm64-Portable.zip`）
2. 任意のディレクトリに展開
3. `cc-switch-remote.exe` を実行

## macOS

### 手動ダウンロード

1. `CC-Switch-Remote-v{バージョン}-macOS.dmg`（推奨）または `CC-Switch-Remote-v{バージョン}-macOS.zip` をダウンロード。Universal パッケージなので、Apple Silicon と Intel Mac のどちらでもネイティブに動作します
2. DMG を開く、または zip を展開して `CC Switch Remote.app` を取得
3. 「アプリケーション」フォルダにドラッグ

### 署名と公証

正式リリースの macOS パッケージは、リリース時に Apple の署名証明書が設定されている場合にコード署名と公証が行われ、そのまま開けます。「開発元を検証できません」と表示された場合は「システム設定 → プライバシーとセキュリティ」で許可するか、[Releases ページ](https://github.com/PowerDi/cc-switch-remote/releases) から最新版を再ダウンロードしてください。

## Linux

CC Switch Remote の Linux 版には **glibc 2.35+** と **WebKitGTK 4.1** が必要です（例：Ubuntu 22.04+、Debian 12+、比較的新しい Fedora）。RHEL / Rocky / Alma 8–9 はシステムライブラリのバージョンが足りないため、現在非対応です。

### ArchLinux

AUR ヘルパーを使用してインストール：

```bash
# paru を使用
paru -S cc-switch-bin

# または yay を使用
yay -S cc-switch-bin
```

### Debian / Ubuntu

1. アーキテクチャに合わせて `CC-Switch-Remote-v{バージョン}-Linux-x86_64.deb` または `CC-Switch-Remote-v{バージョン}-Linux-arm64.deb` をダウンロード
2. インストール：

```bash
sudo dpkg -i CC-Switch-Remote-v{バージョン}-Linux-*.deb

# 依存関係に問題がある場合
sudo apt-get install -f
```

### Fedora などの RPM 系ディストリビューション

1. アーキテクチャに合わせて `CC-Switch-Remote-v{バージョン}-Linux-x86_64.rpm` または `CC-Switch-Remote-v{バージョン}-Linux-arm64.rpm` をダウンロード
2. インストール：

```bash
sudo dnf install ./CC-Switch-Remote-v{バージョン}-Linux-*.rpm
```

### AppImage

上記のシステム要件を満たしているものの、対応するパッケージがないディストリビューション向けです。

1. アーキテクチャに合わせて `CC-Switch-Remote-v{バージョン}-Linux-x86_64.AppImage` または `CC-Switch-Remote-v{バージョン}-Linux-arm64.AppImage` をダウンロード
2. 実行権限を追加：

```bash
chmod +x CC-Switch-Remote-v{バージョン}-Linux-*.AppImage
```

3. 実行：

```bash
./CC-Switch-Remote-v{バージョン}-Linux-*.AppImage
```

### Flatpak

公式 Release には Flatpak パッケージは含まれていません。必要な場合は `.deb` から自分でビルドできます。リポジトリの [flatpak/README.md](https://github.com/PowerDi/cc-switch-remote/blob/main/flatpak/README.md) を参照してください。

## インストールの確認

インストール完了後、CC Switch Remote を起動します：

1. アプリウィンドウが正常に表示される
2. システムトレイに CC Switch Remote のアイコンが表示される
3. 左サイドバーのアプリリストに表示設定済みの管理対象アプリが並び、クリックすると該当アプリのプロバイダーページに入れる

## 自動更新

CC Switch Remote には自動更新機能が内蔵されています：

- 起動時に自動で更新を確認
- 新しいバージョンがある場合、画面に更新通知を表示
- クリックするとダウンロードしてインストール

「設定 → バージョン情報」から手動で更新を確認することもできます。

## アンインストール

### Windows

- 「設定 → アプリ」からアンインストール
- またはインストールディレクトリのアンインストーラーを実行

### macOS

- `CC Switch Remote.app` をゴミ箱に移動
- オプション：設定ディレクトリ `~/.cc-switch-remote/` を削除

### Linux

```bash
# Debian/Ubuntu
sudo apt remove cc-switch

# Fedora などの RPM 系ディストリビューション
sudo dnf remove cc-switch

# ArchLinux
paru -R cc-switch-bin
```
