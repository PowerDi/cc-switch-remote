# CC Switch Remote v4.0.9

上游基线：**v4.0.4**（`farion1231/cc-switch`，已发布 tag）。本版给远程管理加上**分层连接诊断**，放开 **Windows 上的 SSH 密码认证**，并修正能力门控的缓存失效范围。

## 新增

- **显式的连接测试入口**：远程服务器页的健康检查卡片新增「测试连接」。点击后分别报告两层状态——**SSH 连接**（已连通 / 未连通 / 未知）与**远程 Helper**（已安装 / 未安装 / 无法运行 / 未知），并给出对应下一步建议，不再只给一个「失败」。
- **Windows SSH 密码认证**：密码认证不再只支持 Unix 桌面。Windows 下由随应用安装的 `cc-switch-remote-askpass` 组件把本机保存的密码交给 OpenSSH，无需另装 sshpass/plink。其他平台不支持时会明确提示改用密钥文件或 SSH Agent。

## 修复

- **不再把「没装 Helper」显示成「未连接」**：连接失败会区分 SSH 传输失败、SSH 认证失败、Helper 未安装、Helper 无法运行（例如误装了依赖桌面库的构建）。
- **失败时也给出分层结论**：原来的「检查」按钮以及 Helper 安装失败，同样会补做一次分层诊断；设置页的不可用状态也会显示失败发生在哪一层。
- **能力门控按当前管理目标失效缓存**：设置页刷新或安装 Helper 后只失效当前 revision 的 `installed-capabilities` 查询，避免模式面板沿用上一个管理目标的判断；缺数据时按「检查中」处理，只有明确的不可达才算不支持。

## 升级说明

- **无需重装远端 Helper**：本版改动都在桌面端。
- **无数据库 schema 变更**。
- 已安装 v4.0.5 或更新版本的用户可通过应用内更新；更早版本需先手动安装一次 fork 版本。
- Windows 用户安装本版后即可使用密码认证。首次使用建议点一次「测试连接」确认；若提示缺少 askpass 组件，说明安装包不完整，请重新安装。

## 下载

- **macOS**：`CC-Switch-Remote-v4.0.9-macOS.dmg` 或 `.zip`
- **Windows**：`CC-Switch-Remote-v4.0.9-Windows.msi` 或 `-Windows-Portable.zip`
- **Linux (x86_64 / arm64)**：`CC-Switch-Remote-v4.0.9-Linux-*.AppImage` / `.deb` / `.rpm`
- **Remote Helper**：由 `Remote Helper Artifacts` 工作流单独维护在 `remote-helper-latest`（本版未改动 Helper）

macOS 版本是否签名/公证以该平台发布工作流结果为准；未签名/未公证时，首次打开可能需要在系统设置中手动允许。
