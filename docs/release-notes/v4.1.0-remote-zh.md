# CC Switch Remote v4.1.0

上游基线：**v4.0.21**（`farion1231/cc-switch`，已发布 tag，上一基线为 v4.0.4）。本版合入上游 v4.0.5 至 v4.0.21 的全部更新，并为新增功能补上远程管理支持，重点是 **Oh My Pi（OMP）**。

## 新增

- **Oh My Pi（`omp`）**：本机和远程主机都可以管理 OMP 的供应商（写入 `~/.omp/agent/models.yml`）、MCP、提示词、Skills 和会话，也能在应用页安装和更新 OMP。远程操作复用桌面端相同的 Rust 实现，需要远程 Helper 声明 `omp` 能力。与上游一致，OMP 不接本地路由、不统计用量。
- **上游 v4.0.5 至 v4.0.21 的功能**：聚合模式、Claude Code 多个官方订阅账号切换、供应商卡片显示套餐与额度、Codex 模型列表拖动排序、可拖动的应用顺序、新版用量页筛选与定价设置等。完整内容见上游 [v4.0.21](https://github.com/farion1231/cc-switch/releases/tag/v4.0.21) 及更早版本的发布说明。
- **新的远程 Helper 能力**：`pi-native-state`（远程 Pi / OMP 当前状态）、`opencode-default-model`（远程设置 OpenCode 默认模型）、`usage-first-date`（远程用量页的最早日期）。旧 Helper 没有这些能力时，对应入口会提示更新 Helper，用量热力图退回只显示最近一段时间。

## 修复

- 合并后补齐远程目标的传递：用量页的筛选、定价和趋势，路由 / 聚合设置弹层，账号额度，侧栏状态，应用显示与排序，OpenCode 默认模型。选择远程主机时，这些读写都发往该主机，不再落到本机。
- OMP 提示词保存失败时，保留原有文件和数据库状态。
- 上游去掉认证中心的「删除全部账号」后，注销进行中的锁定改为作用在每个账号的「删除账号」上。

## 远程暂不支持

以下功能保持本机专属，远程目标下入口隐藏或说明原因：Kimi 和 Agy 应用、Claude / Kimi / Agy 原生账号登录、远程卸载工具、会话正文阅读、本地路由客户端地址设置。

## 升级说明

- **数据库 schema 从 20 升到 23**，只新增字段，已有数据保留。升级后**不能再回退到 v4.0.9**：旧版本会因为数据库版本过新而拒绝启动。
- **建议更新远程 Helper**：OMP 和上面三项新能力都需要新版 Helper。远程服务器页会显示「有新版」，点击更新即可。新 Helper 会把远程主机上的数据库同样升级到 schema 23。
- 已安装 v4.0.5 或更新版本的用户可通过「关于」页的应用内更新升级；应用因数据库问题无法打开时，恢复页的「检查更新」同样可用。
- 升级后首次打开会依次显示上游 v4.0.10 至 v4.0.21 的更新摘要。
- 更新器签名公钥 key id：`E490AF071AC1237F`。
