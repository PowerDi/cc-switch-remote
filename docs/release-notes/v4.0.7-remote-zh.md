# CC Switch Remote v4.0.7

上游基线：**v4.0.4**（`farion1231/cc-switch`，已发布 tag）。本版只做命名统一，没有功能行为变化。

## 本版内容

### 用户可见的自称统一为「CC Switch Remote」

本机常常同时装着官方 CC Switch，之前不少界面只写「CC Switch」，两个应用在托盘、任务栏和窗口里分不出来。本版把这些位置统一为 **CC Switch Remote**：

- **托盘**：菜单（打开 / 退出 / 退出并停路由）、悬停提示、问题行文案，四种语言同步
- **侧栏**：品牌名与底部版本行
- **Claude Desktop**：MCP 配置里登记的 profile 名（在 Claude Desktop 中直接可见）
- **本地代理报错**：`CC Switch Remote local proxy / routing …`
- **应用内文案**：会话记录说明、远程配置目录与目录设置错误、模型映射说明、托管账号删除提示、导入导出与高级设置描述、请求头占位符
- **四语言文案**：Pi 状态提示、卸载保留提示、火山方舟推广文案

指上游产品/上游数据目录的地方（例如官方 CC Switch 的 `~/.cc-switch`、上游仓库名）保持原样，不做改名。

## 升级方式

从 v4.0.5 起更新器 endpoint 与签名链都属于本 fork，**已装 v4.0.5 / v4.0.6 的用户可直接在应用内更新**；更早版本仍需手动安装一次。

- **macOS**：`CC-Switch-Remote-v4.0.7-macOS.dmg` 或 `.zip`（未签名/未公证）
- **Windows**：`CC-Switch-Remote-v4.0.7-Windows.msi` 或 `-Windows-Portable.zip`
- **Linux (x86_64 / arm64)**：`CC-Switch-Remote-v4.0.7-Linux-*.AppImage` / `.deb` / `.rpm`
- **Remote Helper**：由 `Remote Helper Artifacts` 工作流发布在 `remote-helper-latest`

更新器签名公钥 key id：`E490AF071AC1237F`。
