# CC Switch Remote v4.0.6

上游基线：**v4.0.4**（`farion1231/cc-switch`，已发布 tag 提交 `a29a4f38`）。本版只包含 fork 侧修复，基线未变。

## 修复

### 1. 远端会话 panic：Helper「显示安装但装不成功、也没有原因」

用户实机反馈的根因在崩溃日志里可见：

```
internal error: entered unreachable code: identity without executor or pending start
Location: src/remote/session.rs:409
```

传输层错误后旧代码只清空 `session.executor`，却保留 `identity`，会话便卡在「有 identity、没有 executor、也没有 pending」的状态；**下一条**远程命令在这个状态上触发 `unreachable!()`，tokio worker panic，该命令的 Future 永不返回——界面一直转圈且不报错，看起来像没装上（安装可能已经成功）。

现在丢弃坏会话时会同时清掉 `pending` 并真正关闭对应的 ssh 进程，遇到该状态会**重建会话**而不是崩溃；并补了两个回归测试（其中一个直接复现原崩溃状态）。

### 2. Windows 每次 SSH 连接都弹 cmd 黑窗

远端模块此前直接 `Command::new("ssh")`，没有设置 `CREATE_NO_WINDOW`。现在一次性命令与长连接会话统一走 `ssh_command()` / `ssh_tokio_command()`（Windows 下带该标志），不再弹黑窗。

### 3. Helper 安装不再无限等待，超时会说明原因

远端下载脚本此前没有任何超时，主机网络慢或不通时会长时间干等。现在：

- 远端 `curl` / `wget` 增加连接超时、整体超时与低速中止（持续低于 4KB/s 即切换手段）
- 远端下载 5 分钟、本机下载后上传兜底 15 分钟为上限，超时给出可照做的提示（检查主机能否访问 GitHub 或配置出站代理）

## 升级方式

v4.0.5 起更新器 endpoint 与签名密钥都已归属本 fork，因此**已装 4.0.5 的用户可以直接应用内更新到本版**；更早的版本仍需手动下载安装一次。

- **macOS**：`CC-Switch-Remote-v4.0.6-macOS.dmg` 或 `.zip`（未签名/未公证）
- **Windows**：`CC-Switch-Remote-v4.0.6-Windows.msi` 或 `-Windows-Portable.zip`
- **Linux (x86_64 / arm64)**：`CC-Switch-Remote-v4.0.6-Linux-*.AppImage` / `.deb` / `.rpm`
- **Remote Helper**：由 `Remote Helper Artifacts` 工作流发布在 `remote-helper-latest`

更新器签名公钥 key id：`E490AF071AC1237F`。

macOS 版本未进行 Apple Developer ID 签名和公证，首次打开可能需要在系统设置中手动允许。
