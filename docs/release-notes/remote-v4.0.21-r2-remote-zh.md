# CC Switch Remote v4.0.21-r2

公开 tag：`remote-v4.0.21-r2`；应用和 Helper 版本：`4.0.21-remote.2`。本次仅递增 Remote 修订号，官方基线仍为 `v4.0.21`，没有合并新的上游代码或变更数据库 schema。

## 远程管理修复

- **账号管理**：从新增或编辑供应商打开账号管理时，保持所选远程服务器；关闭面板后继续填写原表单。Copilot 和 xAI 的额度查询也使用该服务器的账号，不再回退到本地。
- **模型表单**：拉取模型时使用当前表单的端点和请求选项，并在远端解析所选供应商的已保存凭据。临时填写的密钥仅用于本次请求；OpenCode、MCode、OpenClaw 和 Hermes 的表单会丢弃过期的请求结果。保存并重新打开时保留模型输出限制等数字字段；已被旧版本覆盖的值不会自动恢复。此次修复不判断具体现场的 Base URL 或服务端故障原因。
- **设置并发**：查询设置不再写回文件；显式更新单项设置时在文件锁内读取最新配置，只写入需要变更的字段。完整设置表单继续保存提交的用户字段，并保留磁盘上最新的后端字段。配置损坏、读取失败或写入失败时，保存报错并保留原文件。

## 下载与升级

- 桌面包仅发布 **Windows x64**（MSI、便携 ZIP）和 **Linux x86_64 / arm64**（AppImage、deb、rpm）；远端 Helper 仅发布 Linux x86_64 / arm64。本次没有 macOS 桌面包或 Helper。
- **请同时升级桌面端和所管理服务器的 Helper。** 在每台服务器升级 Helper 后断开并重新连接该远程目标，让 SSH 会话使用新进程；仅替换磁盘上的 Helper 不会更新旧会话。请在允许远程会话短暂中断时操作，并在重连后确认 Helper 版本及所需能力。
- 已使用 r1 的客户端可按安装方式升级：支持内置更新的安装可从「设置 → 关于」检查更新；数据库恢复页也提供独立的更新检查和安装入口。便携 ZIP、deb、rpm 可从本 fork 的发行页选择对应包手动更新。
