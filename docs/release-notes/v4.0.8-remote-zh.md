# CC Switch Remote v4.0.8

上游基线：**v4.0.4**（`farion1231/cc-switch`，已发布 tag）。本版修正远程 Helper 能力识别，并让 GitHub 更新信息查询失败与远端已安装 Helper 的能力状态分开处理。

## 修复

- **远程模式切换正确识别 `app-mode`**：Helper 返回的 `app-mode` 和 `provider-editor` 先前未被桌面端的能力映射登记，健康检查解析时被丢弃，导致已经支持这些能力的远端仍可能显示“不支持”。现在会正确保留这两个能力。
- **能力检测不再依赖 GitHub 查询**：按应用切换模式等能力门控只查询所选主机的 Helper 状态；GitHub release 查询失败不会再让界面误判 Helper 不支持。
- **区分检测中、连接失败与确实不支持**：模式面板会分别呈现能力检查状态，并提供重新检查入口。
- **改进 Helper 更新查询错误说明**：为 GitHub release metadata 请求增加 15 秒超时，并明确说明该错误只影响桌面端获取最新发布信息，不影响远端已安装版本及能力。

## 升级说明

- 远端 **Helper 4.0.6 已提供 `app-mode` 和 `provider-editor`，无需重装 Helper**；安装本版桌面应用即可修复能力识别。
- **无数据库 schema 变更**。
- 已安装 v4.0.5 或更新版本的用户可通过应用内更新；更早版本需先手动安装一次 fork 版本。
- 更新器签名公钥 key id：`E490AF071AC1237F`。

## 下载

- **macOS**：`CC-Switch-Remote-v4.0.8-macOS.dmg` 或 `.zip`
- **Windows**：`CC-Switch-Remote-v4.0.8-Windows.msi` 或 `-Windows-Portable.zip`
- **Linux (x86_64 / arm64)**：`CC-Switch-Remote-v4.0.8-Linux-*.AppImage` / `.deb` / `.rpm`
- **Remote Helper**：由 `Remote Helper Artifacts` 工作流单独维护在 `remote-helper-latest`

macOS 版本是否签名/公证以该平台发布工作流结果为准；未签名/未公证时，首次打开可能需要在系统设置中手动允许。
